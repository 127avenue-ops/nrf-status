# 연구계획서 쉬운 설명(공개판)

> 원본: https://127avenue-ops.github.io/nrf-status/docs/easy_v2.1.pdf · 이 파일은 AI·검색 도구가 읽기 쉽도록 원본에서 글자만 뽑은 텍스트판입니다(표 모양은 흐트러질 수 있음).

## 공모 연구계획서 쉬운 설명 — 송지수 선생님용 (2026-09-28)

> 2026년 제2차 내부연구사업에 내는 연구계획서(41 v4.0 · 제출본 별첨1 v2.0)를 쉬운 말로 풀었다. 이 설명서는 제출하지 않는다.

### 한 장 요약

- **무엇을 신청하나** — 「근무규칙을 전부 반영한 병동 간호인력 산정: 합성 근무표 편성가능성 계산실험에 의한 1.6 배수 평가와 조건별 최소 인원 지도」. 12개월(착수 = 협약일, 일정안 12월 1주), 연구비 1,000만 원, 연구책임자 송지수(참여율 80%) · 공동연구원 김대연(20%).
- **왜** — 병동 총원은 흔히 하루 교대별 최소 배치 인원의 합에 고정 계수(예: 1.6)를 곱해 정한다. 그런데 한 달 근무표는 휴무·연속근무 상한·야간 뒤 회복·연가·신규/경력 배치 같은 규칙을 **한꺼번에** 지켜야 한다. 같은 1.6이 병동 조건이 달라져도 근무표를 짤 수 있게 해 주는지는 검증된 적이 없다.
- **12개월 동안 하는 일** — 세 단계로 계산한다. 연구 1: 1.6을 가상 병동 세 유형에서 평가한다. 연구 2: 병동 조건을 넓혀 「최소 몇 명이면 되는가」 지도를 만든다. 연구 3: 그 결과를 병동 규칙을 넣으면 배수 범위가 나오는 **배수표와 계산기**로 넓힌다.
- **결과물** — 연구 1·2 논문 원고(대한간호학회지 투고) · 연구 3 원고 · 지도·배수표·계산기 공개 · 국내 학회 발표 2회. 12개월 안의 게재 확정은 약속하지 않는다.
- **말하지 않는 것** — 실제 병동의 안전·적정·최소·최적 인원 확정, 환자 결과 추정, 1.6의 전국·보편 반증, 특정 배수의 **권고**. 결과는 모형 조건부 범위다.


### 무엇을 계산하나 — 거대한 스도쿠

컴퓨터로 가상의 병동 한 달을 만들고, 꼭 지켜야 하는 규칙(hard 규칙 — 주간 휴식·최소 휴무·연속근무 상한 5일·연속 야간 2일·월 야간 8회·야간 뒤 휴무 2일·교대별 신규 상한·교대별 경력자 1명 이상·전월 근무표와의 연속성 등 20개)을 모두 지키는 근무표가 **하나라도 있는지** 판정한다. 가상 한 달을 수백~수천 번 새로 만들어 판정하면, 「이 인원이면 몇 %의 달에서 근무표를 짤 수 있는가(편성가능률)」가 나온다.

- 결과는 네 가지로 적는다: F(근무표 있음) · I(없다는 것이 증명됨) · T(정해진 시간 안에 결론이 안 남) · E(프로그램 오류).
- T는 실패로 세지 않는다. 「적어도 F만큼, 많아야 F+T만큼」으로 범위를 적는다.
- E가 나오면 계산을 멈추고 원인을 찾는다.

### 세 단계

| 단계 | 질문 | 어떻게 |
|---|---|---|
| **연구 1** 측정 도구 검증 | 가상 병동 세 유형에서 1.6 인원은 95% 기준을 넘는가 | 수요 A 5/5/5 · B 7/7/6 · C 9/9/8(주간/저녁/야간). 1.5배~1.7배(올림) 사이 인원을 한 명씩 전부(16칸) 본다. 「1.6 칸」은 하루 수요 × 1.6을 올림한 인원(A 24 · B 32 · C 42명, 관리자 1명 포함). 1.6 칸은 각 1,350번, 나머지는 각 300번 계산. 1.6 칸은 미리 정한 기준으로 「충족·미충족·불확정」 판정 |
| **연구 2** 조건 공간 | 병동 조건이 바뀌면 95%에 처음 닿는 최소 인원(H*)은 어떻게 달라지나 | 여덟 가지 조건(하루 수요 합, 야간 비율, 저녁 비율, 월 휴무 일수, 공휴, 연가, 신규 비율, 경력 비율)을 골고루 300점 뽑아 인원 계단을 훑고 → 경계 근처를 더 촘촘히 → 처음 보는 64개 조건으로 검증 |
| **연구 3** 배수표·계산기 | 우리 병동 규칙이면 몇을 곱해야 하나 | 인원 계단 전체(바닥 위 0~8명)를 칸당 1,000~3,000번 계산 · 결근·교육/파견·신규 비율 확장·야간 전담·12시간 교대 같은 현실 요건 추가 · 배수표와 계산기로 정리 · 실병동 1~2곳의 규정집 규칙 값을 넣어 읽는 법 시연 |

### 배수를 두 조각으로 나눈다

| 조각 | 뜻 | 어떻게 구하나 | 비유 |
|---|---|---|---|
| **바닥(N₀/W)** | 규칙(휴무 일수·야간 상한·연가 등)만으로 「이보다 적으면 무조건 불가능」이 나오는 인원의 배수 | 계산기로 바로 — 근무표를 짜 볼 필요 없음 | 짐을 실어 보기 전, 규칙만으로 정해지는 최소 크기 |
| **웃돈(Δ/W)** | 실제로 근무표를 짜 보면 바닥 위로 더 필요한 몫 | 수많은 가상 한 달을 실제로 짜 보며 측정 | 실어 보니 짐끼리 맞물리지 않아 더 필요한 공간 |

**배수 = 바닥 + 웃돈.** 바닥은 병동이 자기 규칙으로 직접 계산할 수 있고, 웃돈은 이 연구가 측정해 **범위**(하한·관측값·불확실한 구간)로 알려 준다. 계산 횟수가 유한하므로 한 값으로 정해지지 않는 곳이 있을 수 있고, 그럴 때는 억지로 한 값을 짚지 않고 범위로 보고한다.

### 12개월 일정

| 기간 | 하는 일 |
|---|---|
| 1~2개월 | 연구 1 규칙·생성기 잠금 · 자격검증(규칙 위반을 제대로 잡는지) · 파일럿(계산 속도·범위 확인) |
| 2~3개월 | 연구 1 본계산 · 기록 봉인 · 판정 |
| 3~4개월 | 연구 2 준비 · 검증 · 실행 계약 봉인 |
| 4~8개월 | 연구 2 훑기 → 경계 촘촘히 → 새 조건 64개로 검증 · 6개월에 중간 학회 발표 |
| 8~9개월 | 연구 1·2 원고 작성·투고 |
| 9~11개월 | 연구 3 계산 · 배수표·계산기 · 실병동 규칙 대입 시연 · 11개월에 최종 학회 발표 |
| 11~12개월 | 연구 3 원고 투고 · 재현 자료 정리 · 최종 보고 |

**원칙 — 미리 정하고 잠근다.** 무엇을 몇 번 계산하고 어떤 기준으로 판정할지를 결과를 보기 **전에** 실행 계약으로 정하고 해시로 잠근다. 결과를 본 뒤 기준을 바꾸지 않는다. 계산 속도는 각 파일럿에서 재고, 시간이 모자라면 연구 3의 조건 수를 줄이고 연구 1·2를 먼저 끝낸다.

### 왜 IRB 「비대상」인가

사람을 만나거나, 설문하거나, 환자·직원 정보를 쓰지 않는다. 계산에 쓰는 병동은 전부 컴퓨터가 만든 가상 병동이고, 실병동 시연도 규정집에 적힌 **규칙 값**(휴무 일수, 야간 상한 등)만 쓴다. 그래서 인간대상연구 **비대상(N/A)**이며, 신청서 IRB 칸은 「면제」가 아니라 「기타」에 체크하고 사유를 적었다(「심의면제 승인」이라고 쓰지 않는다). 실제 근무표와 대조하는 연구는 이번 과제 밖이며, 하게 되면 별도 IRB와 자료 협약을 거친다.

### 발표(10분 + 질의 5분)에서 나올 만한 질문

1. **「가상 자료로 한 연구를 현장에 쓸 수 있나요?」** — 이 연구는 권고가 아니라 **범위를 계산하는 방법과 표**를 준다. 바닥 인원은 병동이 자기 규칙으로 직접 계산할 수 있고, 웃돈은 모형 조건부 범위로 읽는다.
2. **「1.6이 맞는지 틀리는지 밝히는 건가요?」** — 1.6을 전국적으로 검증하거나 반증하려는 것이 아니다. 미리 정한 가상 병동과 조건 범위 안에서 1.6이 기준을 넘는지, 모자라다면 규칙 계산(바닥)에서 모자란지 근무표 조합(웃돈)에서 모자란지를 나눠 보는 것이다.
3. **「왜 딱 한 숫자로 안 주나요?」** — 계산 횟수는 유한하므로, 95% 근처에서는 한 명 차이를 가르지 못하는 곳이 생길 수 있다. 모르는 구간을 숨기지 않고 범위로 보고하는 것이 이 연구의 원칙이다.
4. **「기존 연구와 무엇이 다른가요?」** — 선행연구는 크게 세 갈래다: 인력 규모와 근무표를 함께 최적화하는 연구, 주어진 인력으로 근무표를 짜는 근무표 문제 연구, 수요 변동·결근을 다루는 시뮬레이션 연구. 구조화 신규성 검색에서 월 hard 근무표의 최소 총원을 「1.6 × 하루 수요」와 같다고 본 검증된 공식은 찾지 못했고, 국내 문헌의 1.4~1.6 계수는 휴가·공휴를 반영한 연간 상근인력 환산(FTE)·예산 배수로 월 근무표 총원과는 다른 양이다. 최초 계산이나 최초 적용을 주장하지 않고, 재현 가능한 측정과 그 측정이 정하지 못하는 범위의 투명한 보고를 기여로 한다.
5. **「공동연구원이 근무표 프로그램 개발자인데 이해상충(COI)은?」** — 소프트웨어의 **규칙 판정 부분만** 읽기 전용으로 쓰고, 서비스·이용자 데이터는 쓰지 않는다. 관계와 관리 방법은 지식재산·이해상충(IP·COI) 소명서로 공개한다(소명서는 두 분 서명 완료).
6. **「12개월에 세 단계가 가능한가요?」** — 계산은 연구진 PC 3대로 하고, 각 단계의 파일럿에서 계산 속도를 잰 뒤 규모를 확정한다. 시간이 모자라면 연구 1·2를 먼저 끝내고, 연구 3은 미리 정한 순서(12시간 교대 → 야간 전담 → 교육·파견 축을 빼고 조건 수를 줄임)로 줄인다.

### 용어 사전

| 용어 | 뜻 |
|---|---|
| hard 규칙 | 한 번이라도 어기면 안 되는 근무 규칙(휴무·연속근무 상한·야간 뒤 회복 등) |
| 편성가능성 · 편성가능률 | 모든 hard 규칙을 지키는 한 달 근무표가 **하나라도 존재하는가** · 가상 한 달 중 그런 근무표가 존재한 비율 |
| W | 하루 교대별(주간+저녁+야간) 최소 배치 인원의 합 = 하루 수요 |
| N₀ (바닥 인원 · 산술 하한) | 규칙만으로 「이보다 적으면 근무표가 불가능」하다고 계산되는 인원. 실제로 기준에 닿는 인원은 더 클 수 있다 |
| 배수 m = H/W | 총원을 하루 수요의 몇 배로 두는지. 1.6이 그 예 |
| Δ (웃돈) | 기준에 처음 닿는 인원과 바닥 인원의 차이. 한 값으로 안 정해지면 범위로 보고한다 |
| τ = 0.95 | 목표 편성가능률 95%. 추정값이 95%를 조금 넘어도 미리 정한 동시 검정에서 넘었다고 단정되지 않으면 「불확정」 |
| 계단 | 바닥 인원에서 한 명씩 올려 가며 보는 인원 칸들 |
| 등장회귀 판독 | 「인원이 늘면 편성가능률도 오른다」고 가정하고 읽는 방법 |
| 부분식별(완성 집합) 판독 | 그 가정 없이, 관측하지 않은 인원·시간 안에 결론이 안 난 계산을 모두 가능성으로 남겨 두고 읽는 방법 |
| Sobol 수열 | 조건을 골고루 뽑는 방법 |
| 봉인 | 계산 전에 계획(실행 계약)을 해시로 잠그고, 계산 뒤에는 기록을 잠가 나중에 바꾸지 못하게 하는 절차 |

### 선생님이 하실 일

1. 제출본 Word(별첨1 **v2.0**)의 **노란 형광 칸 ①~⑬**을 채운다 — 번호별 설명은 「제출본 입력 안내」 문서.
2. 인쇄 → 신청서 1쪽 성명 옆 **(인)** 날인 · 동의서(별첨2)에 서명하고 「동의함」 체크.
3. 스캔한 PDF 2개 + 산출내역 엑셀(별첨3 v2.0)을 선생님 사번으로 rERP에 올린다(공고 접수 마감 9월 30일).
